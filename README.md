# 🔁 群聊转发 chat_bridge

> 把指定群聊的消息原样转发到另一个群聊：文本、图片、合并聊天记录都支持。

一个 AstrBot v4 插件：在目标群登记会话、在源群绑定规则后，源群消息会实时推送到目标群——不加前缀、不加占位，保持原样。

---

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 🔁 实时转发 | 源群消息以机器人身份立即推送到目标群 |
| 📄 纯文本 | 原文转发，不带昵称前缀、不添加任何内容 |
| 🖼️ 图片 | 多策略重建 + 平台缓存引用，尽力保持原样 |
| 📚 合并转发 | 优先平台原生 `forward_group_single_msg` 原样转发（含嵌套记录） |
| 🔢 按群号绑定 | 无需进群，填群号即可配置规则 |
| 🛡️ 管理员控制 | 所有规则命令仅管理员可用 |
| 💾 本地存储 | 规则 JSON 原子写入、损坏自动重建 |

## 🚀 安装

把整个 `chat_bridge` 目录复制到 AstrBot 数据目录的 `data/plugins/` 下，然后在 Dashboard 启用插件（或重启 AstrBot）。

## 📖 使用

配置分两步：

**① 登记目标群**（在接收消息的群里，仅管理员）：

```text
/转发 注册目标 主群
```

**② 绑定源群**（在要转发的群里，仅管理员）：

```text
/转发 绑定 主群
```

**不想进群？按群号配置**（在机器人所在任意会话执行）：

```text
/转发 群目标 主群 <目标群号>    按群号登记目标
/转发 群绑定 主群 <源群号>      按群号绑定源群
```

其他命令：

```text
/转发 解绑 <备注名>    停止当前群转发到该目标
/转发 列表            查看目标与绑定关系
/转发 清空            清空所有目标与绑定
/转发 帮助            查看使用说明
```

## ⚙️ 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `show_sender` | `false` | 是否带上原发送者昵称（默认原样，不带前缀） |
| `forward_images` | `true` | 是否转发图片；无法转发时静默跳过 |
| `forward_merged` | `true` | 是否转发合并转发（聊天记录）消息 |
| `admin_ids` | `[]` | 管理员兜底 ID 列表 |

## 🧠 设计说明

- **原样转发**：转发内容不带前缀、不加占位；机器人自己的消息不会被再次转发。
- **合并转发**：优先用平台原生动作按消息 ID 原样转发（嵌套记录也能保持完整）；平台不支持时回退到拉取重建，仍失败则静默跳过。
- **会话识别**：通过运行时抓取真实会话 ID（UMO）跨平台通用；按群号绑定时自动适配纯数字或 `group_` 前缀格式。
- **数据**：规则保存在 `data/chat_bridge/bridge.json`（旧版本数据会自动迁移），不占用插件目录。

## 🧪 开发

核心逻辑位于 `core/`，均为纯 Python（无 astrbot 依赖），可独立测试：

```bash
python -m pytest tests
ruff check .
```
